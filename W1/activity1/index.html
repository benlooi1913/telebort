About Web Design

Web design is the process of creating websites. It includes both the visual appearance and the functionality of a website.

A website consists of multiple webpages linked together, while a webpage is a single document displayed in a web browser. Think of a website as a collection of related webpages, like a book, and a webpage as a single page within that book.

Key Web Design Concepts

HTML

HyperText Markup Language - the structure of web pages

CSS

Cascading Style Sheets - the styling of web pages

JavaScript

A programming language that adds interactivity to web pages
